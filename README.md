# Until Sunrise

## Controls

| Tipka | Dejanje |
| :--- | :--- |
| <kbd>A</kbd>, <kbd>D</kbd> | Move |
| <kbd>Space</kbd> | Jumps (wall jumps when on wall) |
| <kbd>Shift</kbd> | Dash |
| <kbd>Escape</kbd> | Meni |
| <kbd>R</kbd> | Reset level |

---

## Dodatno

- V igri so deli kjer so na poti stene in da pridete mimo njih sta 2 načina:
  1. Postavite se zraven stene, odprete meni in nato stisnete `D` oz. `A` (odvisno v katero smer želite iti), in se bo character pomaknil naprej kot da stene ne bi bilo.
  2. Drugi način je, da samo dashas skoz.
- Po ledenih delih ne moreš wall jumpat.

---

## ZAGON

### Navodila po korakih za zagon na Windows:
1. Prenesite paket igre `[Until_Sunrise.zip]` ali odprite repozitorij na [povezavi](https://github.com/neyxium/Until-Sunrise/releases/tag/GameJam).
2. Razširite (*Extract*) datoteko `.zip` v poljubno mapo na računalniku.
3. Odprite mapo in zaženite datoteko `[Until Sunrise.exe]`.

> **Kje se nahaja .exe oziroma zagonska datoteka:**  
> Nahaja se v korenu mape z imenom **Until Sunrise**.
